# Aetheria Chronicles

Unduh `aetheria-chronicles.zip` dari branch ini, lalu ekstrak seluruh isinya.

- **Windows:** instal Python 3 jika belum ada, lalu klik dua kali `MULAI-WINDOWS.bat`.
- **macOS/Linux:** buka Terminal di folder hasil ekstraksi dan jalankan `python3 jalankan.py`.

Browser akan terbuka otomatis pada `http://127.0.0.1:8000/`. Biarkan terminal terbuka selama bermain. Tidak perlu npm, database, atau internet saat bermain. Panduan lengkap ada di `PANDUAN.txt` di dalam ZIP.

Paket berisi kode sumber, ilustrasi, launcher, dan pengujian engine. Game dimainkan solo dengan autosave di browser; guild serta peringkat menggunakan companion NPC lokal.
